ATLAS organize UI integration

Insert work/organize-dialogs.html before main scripts in public/index.html.
Load /organize.css and /organize.js after globals api, loggedIn, busy, endConversation, speak, notice, showLogin are available (same setup as daily.js).
Wire voiceOrganize and textOrganize buttons to window.openOrganize().
Call window.handleOrganize(data) on ordinary chat responses before fallback narration; return value true means handled. Drafts stay silent unless user selects Taslağı sesli dinle. Supply {silent:true} if caller already owns narration.
Call window.clearOrganize() on logout/login reset. It clears fields, snapshots, tokens, blob URLs, mic and pending responses. No startup/background timer needed.
Read api('organize',{}) must combine recordItems, changeItems, listItems, archivedListItems, listChangeItems. Reads only on open/tab/explicit refresh/approved writes. Responses containing managementDraft/listsDraft, managementOpen/listsOpen/backupOpen accepted. backupOpen never auto-downloads even if backupFormat supplied.
List backend public fields: archivedListItems separate collection; items include archived rows and restoration is supported. Record archive uses archived_at, not archived boolean.
Supported UI forms: record edit/archive/unarchive, journal undo; list/project creation, rename/archive/restore, item add/title/quantity/edit/status/complete/reopen/archive/restore, journal undo; JSON/CSV/ICS download.
All write buttons request drafts first. Exact signed approvals: managementConfirmation + Değişikliği onaylıyorum; listsConfirmation + Liste değişikliğini onaylıyorum. Closing is blocked only during approval mutation, not pending preview read/download. Mic is explicit one-shot with 15 second cap and stops on hide/logout/close. Shared busy is released before narration finishes.
Tests: node --test test/organize-ui.test.js. No changes made to index/app/experience/worker by frontend agent. Visual browser review reserved for root integration.
